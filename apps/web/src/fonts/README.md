# Bundled fonts

The existing Sora and Plus Jakarta Sans variable fonts are bundled for reproducible offline builds. Downloaded from the official Google Fonts repository on September 18, 2026. Corresponding SIL Open Font Licenses are retained alongside the font files.

- `sora.ttf`: [Google Fonts source](https://github.com/google/fonts/blob/main/ofl/sora/Sora%5Bwght%5D.ttf); SHA-256 `84ff7096ae3ec6c8be47d906d1a0ba4de7f2ce78c615275c77301964a316e16c`.
- `plus-jakarta-sans.ttf`: [Google Fonts source](https://github.com/google/fonts/blob/main/ofl/plusjakartasans/PlusJakartaSans%5Bwght%5D.ttf); SHA-256 `89b3fb38aa0d275d7a731d0d817a4f1622b316b4d7fbdedcf02ee9099ff68bc8`.
