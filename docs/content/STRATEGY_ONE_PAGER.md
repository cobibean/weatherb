## RED FLAG TRIGGERS & FIXES

```
RED FLAG                        → FIX
Engagement < 2%                 → Try more educational threads
Follower growth stalls          → More daily engagement, spicy takes
Testnet signups < 10/day        → Add explainer content, testimonials
0 repeat users                  → Fix UX or messaging
Same 10 people engaging         → Broader audience push needed
No unsolicited testimonials     → Product-market fit issue, investigate
```

## VOICE & TONE (DO'S & DON'Ts)

```
✅ DO THIS                           ❌ DON'T DO THIS
─────────────────────────────────────────────────────────
Authentic founder voice            Corporate marketing speak
Real metrics (even small ones)     Exaggerated claims
Show wins AND failures             Hide problems
Admit uncertainty                  Fake certainty
Respond to feedback                Ignore community
Educational content                Pure hype
Slow, consistent growth            Viral-chasing

EXAMPLE:
✅ "Day 14: 127 bets. People are testing, not gambling."
❌ "MOON INCOMING! 1000% GROWTH! 🚀🚀"
```
